# Marga III ⛵

Projektplanering för restaurering av skärgårdskryssare från 1918.

## Mappstruktur

```
marga/
├── index.html              ← Projektplaneraren
├── bilder/
│   ├── skrov/
│   ├── däck/
│   ├── inredning/
│   ├── motor/
│   ├── roder/
│   ├── rigg/
│   └── dokumentation/
├── dokument/
│   ├── ritningar/
│   ├── offerter/
│   ├── besiktning/
│   └── certifikat/
└── 3d-modeller/
```

## Lägga till filer

1. Kopiera filen till rätt mapp lokalt
2. GitHub Desktop → Commit → Push
3. På github.com: klicka på filen → Raw → kopiera URL
4. Klistra in i planeraren

## URL-format

```
https://raw.githubusercontent.com/ANVÄNDARNAMN/marga/main/bilder/skrov/foto.jpg
```
