# Renovering Marga III ⛵

Projektplanering för restaurering av skärgårdskryssare från 1918.

## Mappstruktur

```
renovering-marga-iii/
├── index.html              ← Projektplaneraren (öppna denna i webbläsaren)
├── bilder/
│   ├── skrov/              ← Foton av skrov, spant, bottenstockar
│   ├── däck/               ← Däck och överbygnad
│   ├── inredning/          ← Kabin och inredningsdetaljer
│   ├── motor/              ← Elmotor och drivsystem
│   ├── roder/              ← Roder och styrinrättning
│   ├── rigg/               ← Mast, bom, segel
│   └── dokumentation/      ← Allmän dokumentation
├── dokument/
│   ├── ritningar/          ← Konstruktionsritningar (.pdf, .dwg)
│   ├── offerter/           ← Offerter från leverantörer
│   ├── besiktning/         ← Besiktningsprotokoll
│   └── certifikat/         ← Certifikat och registrering
└── 3d-modeller/            ← Rhino .3dm-filer
```

## Lägga till filer

1. Kopiera filen till rätt mapp lokalt
2. GitHub Desktop → Commit → Push
3. På github.com: klicka på filen → "Raw" → kopiera URL:en
4. Klistra in i planeraren

## URL-format

```
https://raw.githubusercontent.com/DITT-ANVÄNDARNAMN/renovering-marga-iii/main/bilder/skrov/foto.jpg
```

## Aktivera GitHub Pages

Settings → Pages → Source: Deploy from branch → main → / (root) → Save

Planeraren finns sedan på:
https://DITT-ANVÄNDARNAMN.github.io/renovering-marga-iii
